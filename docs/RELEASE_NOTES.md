## Jagunco 1.1.0

- Concessão de XP pela central com validação da vida atual, limite por
  operação e recibo durável contra pagamentos duplicados.
- Instalação independente com MySQL, backup, restauração e rollback por
  imagem imutável. A central continua opcional.
- Node 26.13.1 como runtime principal e 24.22.3 para compatibilidade.
- CI de gameplay, mobile, recompensas MySQL, instalação e segurança.
- Imagens candidatas com digest, SBOM e proveniência BuildKit, além de
  atestação assinada pelo GitHub Actions para a imagem pública.

Os arquivos desta release descrevem a revisão e a imagem publicadas.
Uma release não implanta automaticamente o jogo em produção.
